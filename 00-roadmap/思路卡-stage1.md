## 01 · 判断素数（你已 4/6，只差三处）

### 题目本质

判断一个数 `n` 除了 1 和它自己，**还有没有别的因子**。

### 需要什么语法

- `if` 判断边界
- `for` 循环试除
- `%` 取余判断整除

### 分步思路

```
第一步：处理边界
    n <= 1 的数都不是素数 → 直接返回"否"

第二步：从 2 开始，试到 √n
    为什么要到 √n 而不是 n？
    因为如果 n = a × b 且 a ≤ b，那一定有 a ≤ √n。
    试过 √n 以内的所有数都不整除，就说明没有因子。
    （代码里用 i*i <= n 代替 i <= √n，避免浮点）

第三步：循环里只做一件事
    如果 n 能被 i 整除 → 立刻返回"否"

第四步：循环结束后
    能走到这里，说明一个因子都没找到 → 返回"是"
```

### 伪代码

```
函数 是素数(n):
    如果 n <= 1: 返回 否

    对于 i 从 2 开始，只要 i*i <= n，i 每次加 1:
        如果 n % i == 0: 返回 否

    返回 是      ← 注意：在循环外面
```

### 你现在的 bug 在哪

| 位置 | 错法 | 为什么错 |
|---|---|---|
| `else return 1;` | `else` 属于循环里的 `if` | 第一轮不整除就返回"是"，9 % 2 ≠ 0 就直接判成素数了 |
| 函数末尾 `return 0;` | 循环一次没跑（n=2）就掉到这里 | 2 的 √2 < 2，循环不执行，应该返回"是" |
| `scanf("%d",&n);` | 函数里又读了一次输入 | main 已经读过了，函数不该自己拿输入 |

### 常见坑

- `i*i <= n` 别写成 `i < n`（能跑但慢，而且不算错，只是不专业）
- `n == 2` 是素数，别被"偶数不是素数"带偏
- 判题失败时先看是哪个输入错了，别猜

## 02 · 最大公约数与最小公倍数

### 题目本质

- 最大公约数（gcd）：两个数**共同的最大因子**
- 最小公倍数（lcm）= `a * b / gcd(a, b)`（先除后乘防溢出）

**关键：lcm 不需要单独写循环，只要调用 gcd。**

### 需要什么语法

- `while` 循环
- 变量交换（临时变量）
- 取模 `%`

### 分步思路（辗转相除法）

```
求 gcd(a, b):
    只要 b 不为 0:
        临时保存 b
        b = a % b          ← 余数变成新的 b
        a = 临时保存的 b    ← 原来的 b 变成新的 a
    循环结束时 a 就是最大公约数

求 lcm(a, b):
    返回 a / gcd(a,b) * b     ← 先除后乘，防止 a*b 溢出
```

### 伪代码

```
函数 gcd(a, b):
    当 b != 0:
        t = b
        b = a % b
        a = t
    返回 a

函数 lcm(a, b):
    返回 a / gcd(a, b) * b
```

### 为什么这样能work（想明白这题就真会了）

`gcd(12, 18)`：
```
a=12 b=18
t=18, b=12%18=12, a=18
t=12, b=18%12=6,  a=12
t=6,  b=12%6=0,   a=6
b=0 结束，返回 6  ✓
```

**核心直觉**：`gcd(a,b) = gcd(b, a%b)`——两个数的公约数，等于「较小的数」和「余数」的公约数。反复缩小，直到余数为 0。

### 常见坑

- 交换顺序写反（`b = a % b` 必须在 `a = t` **之前**，否则 b 已经是新值了）
- `lcm` 写成 `a * b / gcd`，数大时会溢出
- 忘记 `while` 里更新 `a`

## 03 · 数组统计（最值 + 平均）

### 题目本质

遍历一遍数组，同时求出最大值、最小值、平均值。

**难点在「一次遍历带回三个结果」——要用指针。**

### 需要什么语法

- 数组作参数 `int a[]`
- 指针作参数 `int* max`，返回值靠 `*max = ...`
- `double` 转换

### 分步思路

```
第一步：初始化
    max 和 min 都先设成 a[0]（第一个元素）
    sum 设为 0
    ⚠️ 不要设成 0！如果数组全是负数，max 设 0 就错了

第二步：一次循环
    对每个元素:
        sum += a[i]
        如果 a[i] > max: max = a[i]
        如果 a[i] < min: min = a[i]

第三步：写回结果
    *max = max
    *min = min
    *avg = sum / (double)n      ← 必须强转，否则整数除法丢掉小数
```

### 伪代码

```
函数 统计(a, n, max指针, min指针, avg指针):
    max = a[0]
    min = a[0]
    sum = 0

    i 从 0 到 n-1:
        sum = sum + a[i]
        如果 a[i] > max: max = a[i]
        如果 a[i] < min: min = a[i]

    *max指针 = max
    *min指针 = min
    *avg指针 = sum / n       ← 注意类型转换
```

### 为什么用指针（这题的核心价值）

C 语言的 `return` 只能返回**一个值**。要带回三个结果，有两种办法：

1. **指针**（本课要求的）：把变量的地址传进去，函数直接改外面的变量
2. 返回结构体（第 20 讲才学）

`*max = x` 的意思是「把 x 写到 max 指向的那个地址里」。所以调用方的变量真的被改了。

### 常见坑

- `max = 0` 初始化（全负数时错）
- `sum / n` 没转 double（3/2 得 1 而不是 1.5）
- 忘了 `*`：写 `max = max` 只改了形参
- 忘了 `&`：调用时写 `Stats(a, n, max, min, avg)` 而不是 `&max`

## 04 · 打印乘法表（练输出格式）

### 题目本质

两层循环，外层控制行，内层控制列。**唯一难点是输出格式要对齐。**

### 需要什么语法

- 嵌套 `for`
- `printf` 的格式控制 `%-3d`

### 分步思路

```
外层 i 从 1 到 n:        ← 第 i 行
    内层 j 从 1 到 i:    ← 第 i 行有 i 个式子
        打印 "j*i=结果"，结果占 3 位左对齐
    内层结束后打印换行
```

### 伪代码

```
函数 打印乘法表(n):
    i 从 1 到 n:
        j 从 1 到 i:
            打印 j 和 "*" 和 i 和 "=" 和 (j*i)，结果左对齐占3位
        打印换行
```

### 格式为什么要 `%-3d`

`%-3d` 的含义：
- `%d` 打印整数
- `3` 表示至少占 3 个字符宽
- `-` 表示**左对齐**（不加 `-` 是右对齐）

所以 `1` 会打印成 `"1  "`（后面补两个空格），`12` 打印成 `"12 "`。

**不这样做，位数不同的结果会让列错位，看起来乱七八糟。**

### 常见坑

- 内层 `j <= n` 写成 `j <= n` 而不是 `j <= i`（会打出一个方阵）
- 每个式子后面多打一个空格（判题会失败）
- 内层循环外面的换行放错位置（放在内层里会变成每个式子换行）
- 用 `%3d` 而不是 `%-3d`（右对齐，看着也不对）
