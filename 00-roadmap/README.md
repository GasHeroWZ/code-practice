## 三、判题器怎么用

```powershell
cd D:\个人\code-practice\00-roadmap

.\judge.ps1                  # 判全部 16 题
.\judge.ps1 -Stage 1         # 只判阶段 1
.\judge.ps1 -Problem prime   # 只判名字含 prime 的题
```

输出示例：

```
===== stage1 =====
  [FAIL] 01-is-prime  (3/6)
      用例 case1.in
        期望: yes
        实际: no
```

- `[PASS]` = 该题所有用例通过
- `(3/6)` = 6 个用例过了 3 个，说明思路对但边界没处理
- 会直接打印「期望 vs 实际」，不用猜哪里错

**判题原理**：编译 `main.c` → 把 `caseN.in` 喂给程序 → 比对输出与 `caseN.out`。所以你只需改 `main.c` 里的 `TODO` 部分。

## 四、怎么用（关键：别攒着做）

**节奏：听 1 讲 → 当天做对应阶段的题。**

| 时间 | 做什么 |
|---|---|
| 听课 30 分钟 | 对应讲次 |
| 做题 40 分钟 | 该阶段某一道题 |
| 判题 1 分钟 | `.\judge.ps1 -Problem xxx` |

**三条纪律：**

1. **不许先看别人答案**。卡住先看题目里的 `提示:` 注释。
2. **卡 30 分钟就先跳过**，做下一题，第二天回来。C 语言很多概念是「过一夜就通了」。
3. **每 PASS 一题就 commit 一次**：
   ```powershell
   cd D:\个人\code-practice
   git add .
   git commit -m "feat: 通过 stage1/01-is-prime"
   ```

**常见错误的含义**（比报错本身更重要）：

| 报错 | 真实原因 |
|---|---|
| `implicit declaration of function` | 函数没声明就用了，或拼错名字 |
| `undefined reference to` | 声明了但没实现（链接阶段才报） |
| 输出对但判 FAIL | 多了空格、少了换行、格式不一致 |
| 段错误 / 崩溃退出 | 空指针、数组越界、忘了 malloc |
| 结果随机变化 | 用了未初始化的变量 |

## 五、两个「理解型」问题（第 24-25 讲）

这两讲没有代码题，但要能不看资料回答：

1. **一个 `.c` 文件变成 `.exe` 经过哪几步？** 预处理 → 编译 → 汇编 → 链接。要能说出每一步做什么、`#include` 在哪一步消失、`printf` 是在哪一步才被真正接上的。
2. **`#define N 100` 和 `const int N = 100;` 有什么区别？** 前者是文本替换，预处理阶段就没了；后者是真正的只读变量，占内存、编译期检查类型。

答不出来就回去重看第 24、25 讲。

## 七、学完之后学什么（分析）

### 先明确界线

| 讲次 | 内容 | 归类 |
|---|---|---|
| 第 1-23 讲 | 语法、指针、结构体、动态内存、文件 | **C 语言本体** |
| 第 24-25 讲 | 编译链接、预处理 | C 语言本体（理解型） |
| 第 26-31 讲 | 顺序表、单链表、双向链表、贪吃蛇 | **数据结构** |

**所以「C 语言学完」的界线是第 25 讲。** 你现在这套课件，26 讲开始已经是数据结构了，不是 C 语言。

### 三条可选的下一步

| 路线 | 内容 | 适合谁 | 代价 |
|---|---|---|---|
| **A. 数据结构与算法** | 顺序表、链表、栈、队列、树、排序、查找 | 几乎所有人 | 抽象、烧脑、进度慢 |
| B. C++ / 面向对象 | 类、继承、STL、模板 | 想做 Qt、游戏、图形、大厂 C++ 岗 | 语法量比 C 大很多 |
| C. 直接做项目 | 课程设计、小工具 | 想尽快看到成果 | 缺基础容易卡死 |

### 我的建议：A，理由三条

**1. 你的课件就是为这条路铺的。**
第 26-31 讲已经在讲顺序表、单链表、双向链表、贪吃蛇。你跳过数据结构去学 C++，等于把手上这套课的 1/5 扔掉。

**2. C 语言单独存在没有价值，必须配数据结构。**
你现在能用 C 做的，都是「算个数、求个值」这类小练习。真正让 C 有用的是：链表、树、哈希表——**这些才是数据结构的内容**。不会数据结构，C 就是个算器。

**3. 它几乎是所有后续方向的前置条件。**
- 考研 408：数据结构 45 分（最大单项）
- 实习面试：手写链表反转、判断链表有环，是标准题
- 学 C++ 的 STL：`vector`/`list`/`map` 底层全是数据结构
- 学数据库：B+ 树索引

**唯一例外**：如果你的目标明确是「做 GUI 或游戏」，那就先补 C++。但即便那样，链表和栈也是绕不开的。

### 具体安排（学完 C 之后）

```
第 1 个月：线性表（顺序表、链表、栈、队列）+ 配套 LeetCode 简单题
第 2 个月：树（二叉树遍历、BST、堆）+ 排序算法
第 3 个月：哈希表、图的基础 + 开始做项目
```

并行建议：**每天 20 分钟做一道 LeetCode 简单题**（用 C 写），比集中刷题有效。
