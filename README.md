## 怎么判题

```powershell
cd D:\个人\code-practice\00-roadmap

.\judge.ps1 -List                 # 看全部题目
.\judge.ps1 -Problem table        # 判某一题（对错都显示实际输出）
.\judge.ps1 -Stage 1              # 判一个阶段
.\judge.ps1                        # 判全部 16 题
```

判题器特性：

- 每题编译到独立临时文件，不会被残留进程占用
- 每个用例最多等 5 秒，死循环会被判定超时而不是卡死
- 通过时显示每个用例的实际输出，失败时显示「期望 vs 实际」

## 学习节奏

听 1 讲 → 做对应阶段的题 → 判题 → PASS 后提交。每题 20-60 分钟。

判断「学会」的标准不是能凭空想出来，而是**能看懂、能重写、下次能独立写**。
